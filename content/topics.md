### P4. LINE公式アカウントの友だちを増やす方法10選｜店舗ですぐ使える施策

- 狙うキーワード: LINE公式アカウント 友だち 増やす / LINE公式 友だち追加 方法 / LINE 集客 店舗
- 検索意図: 方法（アカウントは作ったが友だちが増えない、増やし方を知りたい）
- 見出し案:
  1. 友だちが増えない原因（存在を知らない・登録するメリットがない・導線がない）
  2. 店舗でできる施策10選（店内POP・レジ声かけ・名刺にQR・Instagramプロフィール・Googleビジネスプロフィール・ホームページ・初回クーポン・会計時の案内・チラシ・口コミ紹介）
  3. 友だち追加時のあいさつメッセージで離脱を防ぐコツ
  4. やってはいけないこと（しつこい勧誘・関係のない人への一斉送信）
  5. よくある質問（何人くらいで効果が出るか・ブロックされたらどうなるか）
- 依頼につながる理由: 「作ったけど増えない」は最も多い悩み。施策を知っても実行する時間がない経営者に、運用代行の価値を伝えられる
- 事実確認が必要な点: 各施策の効果を断定する数字は使わない。LINE社の友だち追加に関するガイドライン（禁止事項）を公式ヘルプで確認

### P5. ネイルサロン・エステサロンのLINE活用｜予約管理とリピート促進のコツ

- 狙うキーワード: ネイルサロン LINE公式アカウント / エステサロン LINE活用 / サロン LINE 予約
- 検索意図: 業種（ネイル・エステの経営者が、自分の業種でのLINE活用を知りたい）
- 見出し案:
  1. ネイルサロン・エステサロンでLINE公式アカウントが向いている理由（リピート商材・予約が必須・写真映えするメニュー紹介）
  2. 予約の受け方の選択肢と、サロンに合った方法の選び方
  3. 施術前のリマインドと施術後のフォロー配信の例文
  4. クーポン機能で「次回予約」を促す運用の流れ
  5. よくある質問（個人サロンでも使えるか・ホットペッパーとの併用）
- 依頼につながる理由: 第1候補ターゲット業種。美容室・サロンの記事（公開済み）とは業種を分けており、ネイル・エステ特有の運用を知りたい検索者を取り込める
- 事実確認が必要な点: ホットペッパービューティーとLINE併用に関する最新の連携状況。クーポン機能の仕様（LINE公式ヘルプで確認）

### P6. LINEの予約機能と外部予約システムの違い｜店舗に合った選び方

- 狙うキーワード: LINE 予約機能 予約システム 違い / LINE公式 予約 比較 / LINE 予約 連携
- 検索意図: 比較（予約をLINEでやるか、別のシステムを使うか迷っている）
- 見出し案:
  1. LINE公式アカウントの予約機能（「LINEで予約」）でできること・できないこと
  2. 外部予約システム（リザービア、STORES予約など）の特徴と料金帯の目安
  3. LINEの予約機能が向いている店舗・外部システムが向いている店舗の比較表
  4. LINEと外部予約システムを連携させる方法（リッチメニューからの導線）
  5. よくある質問（両方使ったほうがいいか・乗り換えの手間）
- 依頼につながる理由: 予約の仕組みで迷っている人は導入直前。自分に合った方法がわかった後「設定を任せたい」と思えば相談につながる
- 事実確認が必要な点: 外部予約システムの料金・機能は各社の公式サイトで最新情報を確認。特定のシステムを「おすすめ」と断定しない

### P7. LINE公式アカウントのショップカードの作り方と活用のコツ

- 狙うキーワード: LINE ショップカード 作り方 / LINE公式 ポイントカード / LINE ショップカード 使い方
- 検索意図: 方法（ショップカード機能の設定方法を知りたい）
- 見出し案:
  1. LINEのショップカード機能とは（紙のポイントカードをLINE上で再現する仕組み）
  2. ショップカードの作成手順（管理画面のスクリーンショット付き）
  3. 特典の設定のコツ（ゴールまでのポイント数・中間特典・特典の内容）
  4. 業種別の活用例（飲食・サロン・小売）
  5. よくある質問（紙のカードとの併用・有効期限の設定・お客様への案内方法）
- 依頼につながる理由: ショップカードはリピート促進の基本機能。設定方法を調べている人はLINE活用に前向きで、他の機能も含めた設計を相談する導線を作れる
- 事実確認が必要な点: ショップカードの設定画面・仕様の最新情報（LINE公式ヘルプで確認）。スクリーンショットは執筆時に取得する

### P8. LINE公式アカウントのクーポンの作り方と使い方｜再来店につなげるコツ

- 狙うキーワード: LINE クーポン 作り方 / LINE公式アカウント クーポン / LINE クーポン 配信
- 検索意図: 方法（クーポン機能の作り方・使い方を知りたい）
- 見出し案:
  1. LINE公式アカウントのクーポン機能の概要（種類・表示のされ方）
  2. クーポンの作成手順（全員配布型・抽選型の違い）
  3. 再来店につなげる配信タイミングと文面の考え方
  4. クーポンの効果を確認する方法（開封数・使用数の見方）
  5. よくある質問（無料プランでも使えるか・クーポンの乱用対策）
- 依頼につながる理由: クーポンは飲食・サロンの経営者が最も関心の高い機能の一つ。具体的な作り方の記事で信頼を得て、配信の設計や運用全体の相談につなげる
- 事実確認が必要な点: クーポン機能の最新仕様・無料プランでの制限（LINE公式ヘルプで確認）

### P9. 小さなお店がデジタル化でまず取り組むべき3つのこと

- 狙うキーワード: 小さなお店 デジタル化 / 店舗 DX 何から / 個人店 デジタル化 始め方
- 検索意図: 依頼（デジタル化したいが何から手をつけていいかわからない）
- 見出し案:
  1. 「デジタル化」と言っても大げさなシステム導入ではない（身近なところから始められる）
  2. まず取り組むべきこと1: 連絡手段の整理（LINE公式アカウントで問い合わせ・予約を一本化）
  3. まず取り組むべきこと2: 紙の管理をやめる（予約台帳・顧客カードのデジタル化）
  4. まず取り組むべきこと3: 集客の入り口を増やす（Googleビジネスプロフィール・SNS・ホームページ）
  5. よくある質問（費用はどれくらいかかるか・ITに詳しくなくてもできるか）
- 依頼につながる理由: 「何からやればいいか」を調べている段階の経営者は、方向性が見えれば「手伝ってほしい」と思いやすい。RAIZONの事業（LINE構築・DX支援）全体の入り口になる記事
- 事実確認が必要な点: 特定のツール名を出す場合は公式サイトで料金・機能を確認。効果の数字は使わない

### P10. GoogleビジネスプロフィールとLINEをあわせて集客する方法

- 狙うキーワード: Googleビジネスプロフィール LINE連携 / MEO LINE / Google マップ LINE 集客
- 検索意図: 方法（Google検索・マップからの集客をLINEにつなげたい）
- 見出し案:
  1. Googleビジネスプロフィール（旧Googleマイビジネス）とは何か・なぜ店舗に重要か
  2. GoogleビジネスプロフィールにLINEのリンクを設置する方法
  3. 「Google検索で見つける → LINEで予約・問い合わせ」の流れを作る
  4. 口コミ・写真の充実がLINE登録につながる理由
  5. よくある質問（Googleビジネスプロフィールの登録は無料か・MEO対策とは何か）
- 依頼につながる理由: 地域密着のBtoC店舗にとってGoogle検索・マップは最大の集客チャネル。LINE単体ではなく「見つけてもらう→つながる」の全体像を示すことで、RAIZONのDX支援の価値を伝えられる
- 事実確認が必要な点: Googleビジネスプロフィールの設定画面・リンク設置方法の最新情報（Google公式ヘルプで確認）
